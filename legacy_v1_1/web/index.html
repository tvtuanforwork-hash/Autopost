01 · Kết nối Extension

Extension xác thực với Server bằng API Key

Chưa kết nối
1

Chạy python setup.py trên server để tạo API Key.

2

Cài extension từ thư mục extension/ trên trình duyệt.

3

Nhập địa chỉ Server HTTPS và API Key vào Popup của extension, bấm Kết nối.

API Key không xuất hiện trong mã HTML. Web chỉ hiển thị trạng thái kết nối, không lấy cookie trình duyệt.

Kiểm thử

03 · Zalo Cloud · QR & Nhóm

Module thử nghiệm trên server; không can thiệp Zalo PC

Chưa chạy

Muốn chạy thử cần bật profile Zalo trên Cloud. QR chỉ hiển thị sau khi worker khởi động.

Chưa có mã QR hoặc đã đăng nhập.

Phiên Zalo được mã hóa AES-256-GCM trên server; không nhập cookie vào Dashboard.
